# Changes

Every PR adds one change file, `changes/<issue-number>-<slug>.md` (e.g. `6-l10-loadtest.md`), from [`TEMPLATE.md`](./TEMPLATE.md), and fills its issue's line below. Together they are our change log, our record of who was in charge, and our AI-use declaration. A second PR for the same issue uses a different slug and goes on the same line.

**How to add yours:** find the line `<!-- #<your issue number> -->` (it doesn't show on GitHub) and replace it with your entry. Every issue has its own line with a blank line around it, so two PRs never edit the same or neighbouring lines and never conflict. Past #300? Add more slot lines in a small PR labelled `skip-change-file`.

Entry: `- [#<n>](<file>.md) — <what changed> — <in charge>`
