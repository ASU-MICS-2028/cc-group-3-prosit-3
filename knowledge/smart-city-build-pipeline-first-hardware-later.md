Lecturer guidance for Prosit 3: hardware sensors are the bottleneck (a few devices may be available for demos, not one per component), so start on the software side. Build the whole pipeline with synthetic data first; when devices arrive, set them up, calibrate, take measurements, push to the database, and the same pipeline keeps working.

Some lab parts depend on hardware; submit what the pipeline can show without it. Prosit 2 ended around Lecture 10; students were told to start Prosit 3 as soon as Prosit 2 was in. Prosit 3 reports reuse the Prosit 1 template.
