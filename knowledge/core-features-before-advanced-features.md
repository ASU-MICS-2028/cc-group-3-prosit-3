For the Prosit 1 progress presentation the lecturer said the core features must work first; advanced items (AI crop disease detection, blockchain, IoT integration) are optional, and doing one or two as a demo is enough. Heavy ML cannot run on low-end handsets, so it sits on the server, with extension officers or a shared better phone capturing images.

Progress presentations: four groups, 15 minutes each (about 10 talk plus 5 demo), with a working demo.

For SmartCity Accra: ingest, storage and a dashboard first; forecasting and extras after.
