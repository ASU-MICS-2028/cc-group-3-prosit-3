The brief lists choices students justify: IoT platform (AWS IoT Core, Azure IoT Hub, Google Cloud IoT Core), sensor communication (LoRaWAN, NB-IoT, WiFi, Bluetooth mesh), edge computing (Raspberry Pi clusters, NVIDIA Jetson or cloud edge), data pipeline (Kafka, Kinesis, Event Hubs) and time-series DB (InfluxDB, TimescaleDB). Google Cloud IoT Core no longer exists, so that option is unavailable.
