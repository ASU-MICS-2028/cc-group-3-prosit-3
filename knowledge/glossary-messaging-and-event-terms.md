Event-driven architecture: flow set by events such as user actions, sensor outputs or messages. Serverless: provider manages servers. FaaS: code runs on events (Lambda, Azure Functions, Cloud Functions). API gateway: front door for authentication, rate limiting and routing. Messaging: AWS SQS/SNS, Azure Service Bus, Google Pub/Sub; the Lab 10 broker options are Kinesis, Event Hubs, Pub/Sub and Kafka. Relevant because sensor readings are events.
