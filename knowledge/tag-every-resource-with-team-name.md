title: Tag and name every cloud resource with the team name
tags: [cost, process, cloud-basics]

Untagged resources are hard to find, clean up and grade. Put the team name in every resource name or tag (and use one Azure resource group per project, or one GCP project, so everything can be deleted together).

It also makes the decommissioning inventory and cost tracking sheet accurate.

SmartCity Accra: agree a tag set early (team, project, environment) and apply it in Terraform.
