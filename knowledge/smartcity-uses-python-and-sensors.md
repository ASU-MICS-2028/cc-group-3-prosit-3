The lecturer said the SmartCity project involves pulling sensor data and processing it with Python libraries, so students weak in Python should start early. Three projects in total: the first two are done in class, and the third counts towards the final exam. The machine-learning learned elsewhere in the programme is expected to make the SmartCity stage easier.
