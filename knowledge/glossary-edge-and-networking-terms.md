source: Cloud Computing Glossary
---

Edge computing puts computation near data sources to cut response time. VPC is an isolated private cloud network; subnets segment it; an internet gateway connects it to the internet; a NAT gateway lets private instances reach out without inbound access; a security group is a virtual firewall. A load balancer spreads traffic; a CDN serves content from nearby servers. VPN and Direct Connect/ExpressRoute link on-premises networks. NAT gateways are a classic idle-cost item in the decommissioning plan.
