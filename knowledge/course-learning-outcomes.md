The lecturer said quiz and interim-assessment questions are set from these outcomes. Paraphrased:

1. Analyse IaaS, PaaS and SaaS and judge which suits a given organisation (including cost at startup level).
2. Design and implement scalable, fault-tolerant architectures using virtualization, containers and serverless.
3. Build CI/CD pipelines for continuous delivery of cloud applications (GitHub is the starting point).
4. Evaluate and optimise resource use, performance and cost through monitoring, scaling and capacity planning. Example given: VMs left running burn your credit, so learn when to stop them.
5. Use edge and fog computing for latency-sensitive, distributed applications.
6. Assess emerging trends: AI-enabled cloud management, green computing, multi-cloud orchestration.
7. Collaborate in teams: project management, communication, industry context.

For SmartCity Accra: outcomes 2, 4 and 5 map directly onto auto-scaling, monitoring/cost, and edge processing for sensors.
