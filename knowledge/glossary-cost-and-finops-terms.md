Pay-as-you-go bills for use. Reserved instances discount a commitment. Spot instances use spare capacity cheaply but can be interrupted. Resource tagging labels resources for cost and ownership tracking, which Lab 11's tag-filtered audit and showback report rely on. Cost optimization is continuing waste removal. FinOps brings financial accountability to variable cloud spend. TCO is total cost of ownership; ROI return on investment.
