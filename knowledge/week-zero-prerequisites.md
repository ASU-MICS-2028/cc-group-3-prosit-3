Because classmates come from very different backgrounds, a "week zero" lab pack covers the skills everything else builds on: Linux command line, Docker, GitHub (repository, feature branches, building an image) and basic database interaction. It is not graded, and the lecturer asked anyone unsure to work through it on their own before Lab 1. Later labs add CI/CD with commits and pushes to the team's GitHub repository.

For SmartCity Accra: the pipeline, containers and broker setup all assume these basics.
