---
title: Virtualization turns physical resources into virtual ones; a hypervisor manages the VMs
tags: [virtualization, cloud-basics]
source: Study Session 1
---

Virtualization converts a physical IT resource into a virtual one: servers become VMs, storage becomes virtual storage, routers become logical networks (VLANs), UPS units become virtual UPSs. Software that runs on the host and manages VMs is a virtual machine manager/monitor, or hypervisor. Containers are lighter, giving only the resources the hosted program needs; serverless runtimes remove server provisioning altogether.
