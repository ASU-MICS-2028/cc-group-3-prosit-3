A data lake stores raw data of any structure; a data warehouse holds structured data for analysis (Redshift, BigQuery, Synapse). ETL copies data between systems. OLTP handles transactions; OLAP supports analysis. DBaaS is a managed database (RDS, Cloud SQL). Object, block and file storage differ by access style. ML terms in the glossary: AI, ML, DL, NLP, CV, EDA. KPI is a key performance indicator. Relevant to SmartCity sensor storage and ML.
