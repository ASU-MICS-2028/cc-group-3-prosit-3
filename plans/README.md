# Plans

One plan per issue: `plans/<issue-number>-<slug>.md`, from [`TEMPLATE.md`](./TEMPLATE.md). Fill your issue's line below when you add a plan, and update its status (stub → planned → in progress → done) on that same line.

**How to add yours:** find the line `<!-- #<your issue number> -->` (it doesn't show on GitHub) and replace it with your entry. Every issue has its own line with a blank line around it, so two PRs never edit the same or neighbouring lines and never conflict. Past #300? Add more slot lines in a small PR labelled `skip-change-file`.

Entry: `- [#<n>](<file>.md) — <title> — <owner> — <status>`
